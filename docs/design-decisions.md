# 有意为之的行为（提交 Bug 前请先阅读）

本文件列出乍看像缺陷、实为决策的行为，并附上理由和固定该行为的测试。审计、审查机器人或贡献者发现其中一项时，只有在理由不再成立时才应报告——且报告应指出下文哪句话有误。每条都注明该决策在代码中的位置，以便对照代码树核查，而非对照本说明。

此前三轮审查（2026-09-12）重复报告了其中若干项，本文件因此存在。决策变更时，请在同一 PR 中修改对应条目。
